          Sincronizar entre celular y PC

          La app no tiene cuentas ni login: tus tareas se guardan solo en este navegador. Para llevarlas a otro dispositivo, exporta un archivo aquí y luego impórtalo allá (por AirDrop, correo, WhatsApp, etc.). Repite cuando quieras actualizar.

          Sobre las notificaciones automáticas

          Esta app funciona sin servidor: todo se guarda solo en este dispositivo (IndexedDB) y las alertas se generan localmente, con la Web Notifications API.

          Límites que debes conocer:

          • Si el navegador está completamente cerrado, o el celular/PC está apagado, la notificación de las 7:00 a.m. no puede dispararse — no hay ningún proceso corriendo que la genere.
          • Instalada como app (PWA) y con el navegador abierto en segundo plano, el Service Worker intenta enviarla igualmente usando "Periodic Background Sync" si tu navegador lo soporta (por ahora, principalmente Chrome/Edge en Android y escritorio).
          • Como respaldo, siempre verás el resumen "Pendientes de hoy" arriba, apenas abras la app, sin depender de la notificación del sistema.
          • Si necesitas notificaciones 100% confiables, incluso con el dispositivo apagado o la app cerrada por completo, la única forma real es tener un backend con notificaciones push (ej. Firebase Cloud Messaging, OneSignal, o un servidor propio con Web Push), que envíe la alerta desde afuera del dispositivo.
